# RailsForge — Supercharged Ruby & Rails IDE

The all-in-one developer platform for **Ruby and Ruby on Rails** in VS Code and Cursor.

## Features

- ⚡ **ActiveRecord Schema Peek**: Instant hover cards and autocompletion for database columns, types, and defaults.
- 🚀 **Fast MVC Navigation**: Instant jumping between Model, Controller, View, Spec, Service, and Migration (`Alt+R` / `Cmd+Alt+R`).
- 🛣️ **Route Resolver**: Instant route search and URL helper completions (`users_path`, `edit_order_url`).
- 🧹 **RuboCop Real-time Engine**: Inline diagnostics, 1-click line disables, and safe/unsafe autocorrect on save.
- 🛡️ **Brakeman Security Audits**: 1-click vulnerability scans for SQL injection, mass assignment, and XSS.
- 🧱 **Architecture Refactoring**: Extract selected code directly into clean Service Objects (`app/services`) or Query Objects (`app/queries`).
- 🤖 **`@rails` AI Chat Participant**: Local Ollama-powered AI grounded with active database schema, routes, and Rails best practices.

## Installation

```bash
code --install-extension railsforge.vsix
```
or
```bash
cursor --install-extension railsforge.vsix
```
